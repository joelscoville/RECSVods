# Recording checks

These files retain diagnostic evidence and earlier processing provenance. Current
audio sampling appends reports here; the site never reads this directory.

Older sections and their original service IDs describe the retired format. References
to `service.yaml`, chapter lineage or explicit vector regeneration are historical,
not current instructions. Active playback flags are now `uploadQuirks` on an upload
in `services/<recording-id>.yaml`; see [recording quirks](../quirks.md). Search vectors
are generated during builds from published text, independently of this evidence.
